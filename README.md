# EV Charging Bay 3

This repository contains the ESP32-based implementation and Wokwi simulation files for Charging Bay 1 of the Edge AI Based Smart EV Charging Station Optimizer.

## Project Overview

Bay 1 is part of a multi-bay smart EV charging system designed for monitoring and managing charging parameters using an ESP32-based controller.

The overall project uses IoT communication and a ThingsBoard dashboard for monitoring and management.

## Technologies Used

- ESP32
- Arduino C/C++
- PlatformIO
- Wokwi
- MQTT
- ThingsBoard
- IoT

## Project Files

- `src/` – ESP32 source code
- `diagram.json` – Wokwi circuit configuration
- `platformio.ini` – PlatformIO project configuration
- `wokwi.toml` – Wokwi simulation configuration

## Part of

**Edge AI Based Smart EV Charging Station Optimizer**

This repository represents the individual implementation for Charging Bay 1.
